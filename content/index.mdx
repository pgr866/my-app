## Getting started

Write your documents as `.mdx` files inside `/content`. Every heading you add shows up in the table of contents on the right.

### Installation

Install the dependencies and start the development server.

### Configuration

Pages are configured with a small frontmatter block at the top of each file.

## Writing content

Documents support Markdown and MDX, so you can mix text with components.

### Headings

Use `##` for sections and `###` for subsections. The table of contents nests them.

### Code blocks

Fenced code blocks get syntax highlighting and a copy button.

## Deployment

The site is exported as static files and published on GitHub Pages.

### Build

The build generates the static site in the `out` folder.

### Publish

Every push to `main` builds and deploys the site again.
